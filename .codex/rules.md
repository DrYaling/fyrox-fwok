# FWOK 项目规范
- 使用 Rust 2021；workspace 按运行时、插件、绑定和工具职责分层，不复制 Fyrox Editor 源码。
- 中文代码注释和文档；英文类型、函数和资源名。
- 引擎依赖固定到 `../Fyrox`；编辑器与 Project Manager 通过 `scripts/` 调用已编译程序。
- 游戏逻辑放在 `game` 插件库；窗口入口只放在 `executor`。

## 模块化与单一职责（强制）

- 所有新增或修改的代码必须按领域职责拆分模块。一个模块只负责一个内聚的能力边界；不要在同一文件混合玩法状态、引擎生命周期、UI 构建、输入处理、Lua 注册、文件 I/O 或工具流程。
- `lib.rs`、`main.rs` 和插件入口只负责模块声明、依赖装配、生命周期编排和公共导出；具体业务逻辑必须下沉到职责明确的模块。
- 一个文件同时出现两类以上独立变化原因时，必须拆分。典型边界包括：`state`（领域状态）、`scene`（场景装配）、`interface`（UI）、`input`（输入映射）、`lua_api`/`bindings`（脚本接口）、`runtime`（运行时）、`config`（配置）、`events`（事件）和 `tools`（工具链）。
- 类型、函数和接口必须放在其所属领域模块中，并保持归类一致：同一模块的公开项应服务于同一能力；禁止把无关类型堆放到通用 `utils`、入口文件或单一“管理器”文件中。
- 公共接口遵循接口隔离：每个 trait/API 只表达一个能力，方法保持内聚；当接口同时服务多个不相关调用方或包含可独立演进的方法组时，拆成多个窄接口。优先使用明确的领域类型、枚举和命令/事件传递，避免跨模块暴露引擎内部可变状态。
- 依赖方向必须清晰：底层领域模块不得反向依赖入口或具体 UI；跨边界通过参数、返回值、命令或事件通信。需要共享状态时定义最小的 typed bridge，并明确所有权、线程安全和生命周期。
- 文件规模是拆分信号而非目标：当文件超过约 300 行、公开项属于多个领域，或一个函数同时完成多个阶段时，必须在提交前重新评估边界并优先拆分；若确实不能拆分，应在代码评审说明原因。
- 新模块必须有对应测试或可验证的最小行为；测试应跟随被测职责，禁止用一个大型集成测试掩盖模块边界问题。重构模块时保持外部行为，并同步更新文档和导出。

## Rust 性能与内联（强制）

- Rust 函数如果不涉及遍历、递归、阻塞 I/O、分配大对象或大量计算，默认必须添加 `#[inline]`；典型对象包括简单访问器、句柄/数值转换、轻量构造器、状态查询和小型桥接方法。
- 函数包含循环、递归、复杂分支、大量计算、阻塞操作或较大的函数体时，不得为了形式统一强制内联；应让编译器自行决定，必要时在评审中说明原因。
- `#[inline]` 应放在函数定义上，并与 `#[cold]`、错误处理和性能关键路径的设计保持一致；不得通过内联掩盖错误的模块边界或复制业务逻辑。
- 新增或修改 Rust API 时，应在代码审查中检查是否满足该内联规则；对性能敏感的绑定热路径优先使用 `#[inline]`，并通过 benchmark 或 profiling 验证收益。

## 提交前检查

- 能否用一句话说明每个文件的唯一职责？
- 入口文件是否只做编排和导出？
- 每个公开类型/API 是否属于当前模块，是否存在无关方法或泄漏内部状态？
- 模块之间是否通过稳定的类型/事件通信，而不是互相读取实现细节？
- 新增逻辑是否有针对所属模块的测试或明确的验证命令？
# 资源优先规则

除非需求明确要求动态生成，否则所有 UI、场景节点、组件和预制体必须先在 `.ui`、`.rgs` 或预制体资源中创建，再由 Lua 通过通用 `find`/组件接口获取并操作。Rust 绑定层只提供通用 userdata、句柄查找、消息和生命周期能力，不得按业务名称创建或处理中转 UI/Node 逻辑。Lua 业务脚本不得依赖 `create_*` 生成生产对象；新增 `require` 时必须提供跨模块调用和 Lua 内对象创建测试。

Lua 源码唯一目录是 `./data/scripts`，必须与 `fyrox-lua.toml` 的 `script_root` 一致。禁止在仓库其他目录放置运行 Lua，也禁止在 `.rgs`、预制体中内嵌 Lua 源码做调试或测试；场景组件只能引用 `data/scripts` 下的外部脚本资源。

## 资源与运行验收

- `data/unnamed.ui` 和 `data/scene.rgs` 是节点/组件的唯一事实来源；运行时 Lua 只能 `find`、缓存并操作已有资源。
- Rust 不得按业务名称分支、创建业务 UI/场景节点、实现聊天/背包/技能流程或添加 UIHosts/Interface 中转层；绑定层只提供通用 userdata、句柄校验、查找、消息和生命周期调度。
- `create_*` 仅可用于通用绑定测试，不得被生产 Lua 调用。
- “出现 Lua 日志”不等于 UI 已接入。验收必须看到资源节点存在、`ui.find resolved existing UI node`、UI `draw_commands > 0`，以及真实按钮点击进入 Lua 回调。
- 缺失资源必须诊断并保持 unresolved，禁止静默创建替代节点或保留幽灵代码路径。
